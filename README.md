# Neon Arena FPS

Минималистичный 3D FPS-прототип для ПК на Godot 4.

## Управление
- WASD — движение
- мышь — обзор
- ЛКМ — стрельба
- R — перезарядка / респавн
- Esc — отпустить мышь

## Сборка
Откройте проект в Godot 4.5.1 и запустите `main.tscn`.

GitHub Actions автоматически собирает Windows EXE при push в `main` и прикладывает его как artifact `NeonArenaFPS-Windows`.
